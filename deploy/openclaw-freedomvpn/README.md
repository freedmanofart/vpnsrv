# OpenClaw для Freedom VPN

Изолированный Telegram-помощник на официальном OpenClaw. Групповой агент отвечает на вопросы поддержки и видит только очищенный health-снимок. Отдельный MCP-шлюз даёт владельцу в личном чате ограниченные средства просмотра и изменения; сам OpenClaw не подключается к сети VPN-сервисов и не получает Docker socket.

## Возможности

В группе:

- ответы на обычные вопросы Freedom VPN на русском;
- read-only проверка текущего очищенного health-снимка;
- без доступа к данным пользователей и платежам.

В личном чате владельца:

- поиск аккаунта и последней подписки по Telegram ID;
- просмотр последних платежей по Telegram ID без реквизитов, provider ID и чеков;
- безопасная сводка конфигурации, включённых функций и готовности интеграций без секретов;
- просмотр тарифов и состояния VPN-нод без IP, адресов админки или конфигурационных секретов;
- подготовка изменений статуса поддерживаемых платежей, тарифов и нод;
- проверка доступности и подготовка возврата Platega;
- список ожидающих, истёкших и требующих сверки действий.

Каждое изменение создаёт предпросмотр и одноразовую операцию на 10 минут. Бот применяет её только после отдельного точного сообщения владельца `ПОДТВЕРЖДАЮ <ID операции>` в личном чате. Платёжные статусы Platega меняются только по callback провайдера. Если Platega отправляет возврат на ручную проверку, бот сообщает, что операция ожидает провайдера. Возвраты других платёжных систем не автоматизированы. Все запросы и изменения записываются в audit log.

## Развёртывание

1. Создайте `.env` из `.env.example`, назначьте три разные случайные строки для `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_ADMIN_MCP_TOKEN` и `OPENCLAW_ASSISTANT_TOKEN`, укажите токен Telegram-бота и числовой `OPENCLAW_OWNER_TELEGRAM_ID`. Храните этот файл с правами `0600`.
2. Убедитесь, что Docker network `vpn-backend` уже создан VPN Compose-проектом, а API содержит assistant router и новую Alembic migration.
3. Установите Compose, `assistant-mcp/`, health MCP, `configure-assistant.py`, service/timer и workspace файлы в `/opt/openclaw-freedomvpn/`. Создайте каталоги `state`, `health`, `workspace`; `state` должен принадлежать UID/GID 1000.
4. В `.env` VPN API задайте тот же отдельный `OPENCLAW_ASSISTANT_TOKEN` и `OPENCLAW_OWNER_TELEGRAM_ID`. Примените именно миграцию assistant actions: `alembic upgrade a8b2d91c6f04` (не переключайте остальные миграционные ветви), пересоздайте только сервис API и дождитесь его healthy.
5. Из `/opt/openclaw-freedomvpn` выполните `python3 configure-assistant.py`, затем `docker compose up -d --build`. Скрипт сохраняет резервную копию `state/openclaw.json` и настраивает личный доступ только владельцу, а инструменты admin MCP запрещает для Telegram-групп.
6. Проверьте MCP через `docker compose logs --tail=50 openclaw-assistant-mcp` и `docker compose ps`. После добавления бота отключите Privacy Mode в BotFather и заново добавьте бота в группу.

Не добавляйте `.env`, `state/`, OAuth-креды и рабочие health-файлы в git. Не подключайте OpenClaw gateway напрямую к `vpn-backend`: к этой сети присоединяется только ограниченный MCP sidecar, который принимает соединения с отдельным MCP bearer-токеном.

## Telegram и права

Для группы оставьте `groupPolicy: allowlist`, единственный ID группы и `requireMention: false`. `configure-assistant.py` разрешает личные сообщения только числовому ID владельца и запрещает `freedomvpn-admin__*` во всех группах. Админские операции выполняйте только в личном чате и только после точной строки подтверждения. Отключённый Privacy Mode нужен, чтобы Telegram присылал обычные сообщения группы; затем бота нужно удалить и добавить заново.

## OpenClaw skills

Skills — это инструкции и рецепты, а не сами разрешения и API. Установленный каталог нужно смотреть в Control UI или командой OpenClaw: готовность некоторых skills зависит от приложений, секретов и настройки окружения. Freedom VPN инструменты реализованы отдельно через MCP: `freedomvpn_health` для диагностики и `freedomvpn_*` для личного owner-only режима.
