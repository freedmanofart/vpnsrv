# OpenClaw для Freedom VPN

Изолированный Telegram-помощник на официальном OpenClaw. Групповой агент отвечает на вопросы поддержки; проверка данных и отправка ответов клиентам доступны только текущим администраторам Telegram-группы. Отдельный MCP-шлюз даёт владельцу в личном чате дополнительные средства просмотра и подготовки изменений; сам OpenClaw не подключается к сети VPN-сервисов и не получает Docker socket.

## Возможности

В группе:

- ответы на обычные вопросы Freedom VPN на русском;
- отправка ответа клиенту через VPN-бота по Telegram ID из текущего обращения;
- live-проверки публичного DNS и HTTPS-маршрутов `/health`, `/`, `/cabinet` и защищённых страниц, плюс host health-снимок с его возрастом;
- текущие администраторы группы могут искать аккаунт и последние платежи, читать безопасную сводку конфигурации, тарифы, VPN-ноды и ожидающие операции, а также отправлять ответы клиентам;
- ответы с результатом видны всем участникам закрытой группы Freedom VPN Admin;
- операции изменения и подтверждения в группе недоступны.

В личном чате владельца:

- поиск аккаунта и последней подписки по Telegram ID;
- просмотр последних платежей по Telegram ID без реквизитов, provider ID и чеков;
- безопасная сводка конфигурации, включённых функций и готовности интеграций без секретов;
- просмотр тарифов и состояния VPN-нод без IP, адресов админки или конфигурационных секретов;
- подготовка изменений статуса поддерживаемых платежей, тарифов и нод;
- проверка доступности и подготовка возврата Platega;
- список ожидающих, истёкших и требующих сверки действий.

Каждое изменение создаёт предпросмотр и одноразовую операцию на 10 минут. Бот применяет её только после отдельного точного сообщения владельца `ПОДТВЕРЖДАЮ <ID операции>` в личном чате. Статусы платежей Platega меняются только по обратному вызову платёжной системы. Если Platega отправляет возврат на ручную проверку, бот сообщает, что операция ожидает решения провайдера. Возвраты через другие платёжные системы не автоматизированы. Все запросы и изменения записываются в журнал аудита.

## Развёртывание

1. Создайте `.env` из `.env.example`, назначьте три разные случайные строки для `OPENCLAW_GATEWAY_TOKEN`, `OPENCLAW_ADMIN_MCP_TOKEN` и `OPENCLAW_ASSISTANT_TOKEN`, укажите токен Telegram-бота и числовой `OPENCLAW_OWNER_TELEGRAM_ID`. Храните этот файл с правами `0600`.
2. Убедитесь, что сеть Docker `vpn-backend` уже создана проектом VPN Compose, а API содержит маршруты помощника и новую миграцию Alembic.
3. Установите Compose, `assistant-mcp/`, MCP-модуль проверки состояния, `configure-assistant.py`, файлы служб и таймеров, а также файлы рабочего окружения в `/opt/openclaw-freedomvpn/`. Создайте каталоги `state`, `health`, `workspace`; каталог `state` должен принадлежать UID/GID 1000.
4. В `.env` VPN API задайте тот же отдельный `OPENCLAW_ASSISTANT_TOKEN` и `OPENCLAW_OWNER_TELEGRAM_ID`. Примените именно миграцию assistant actions: `alembic upgrade a8b2d91c6f04` (не переключайте остальные миграционные ветви), пересоздайте только сервис API и дождитесь его healthy.
5. Из `/opt/openclaw-freedomvpn` выполните `python3 configure-assistant.py`, затем `docker compose up -d --build`. Скрипт сохраняет резервную копию `state/openclaw.json`, получает актуальный список администраторов админ-группы Freedom VPN через Telegram Bot API и разрешает только им точный набор инструментов поддержки. Для любого другого отправителя доступ к административному MCP закрыт.
6. Проверьте MCP через `docker compose logs --tail=50 openclaw-assistant-mcp` и `docker compose ps`. После добавления бота отключите Privacy Mode в BotFather и заново добавьте бота в группу.

## Codex и сетевой маршрут

Шлюз использует `HTTP_PROXY` и `HTTPS_PROXY` через вспомогательный контейнер `openclaw-codex-egress`. Он направляет запросы к `chatgpt.com` и `auth.openai.com` через отдельный ретранслятор CONNECT на шведской ноде `sw-node2` по Tailscale. Ретранслятор слушает только `100.117.14.51:18791`, принимает запросы только от главной ноды `100.102.21.123` и разрешает соединения только к этим двум TLS-хостам. К остальным публичным HTTP/HTTPS-адресам вспомогательный контейнер подключается напрямую с главной ноды; частные и локальные адреса блокируются. Telegram Bot API доступен напрямую.

На `sw-node2` установите `deploy/openclaw-freedomvpn/codex-upstream-proxy.py` в `/usr/local/libexec/openclaw-codex-upstream.py`, а `deploy/systemd/openclaw-codex-upstream.service` — в `/etc/systemd/system/openclaw-codex-upstream.service`; затем выполните `systemctl daemon-reload && systemctl enable --now openclaw-codex-upstream`. Проверьте службу командами `systemctl status openclaw-codex-upstream` и `journalctl -u openclaw-codex-upstream`. На главной ноде проверьте `docker compose ps` и `docker compose logs --tail=50 openclaw-codex-egress openclaw-gateway`. Не публикуйте порты `18791` и `3128` в интернете и не расширяйте список разрешённых хостов без проверки.

## Панель управления

Панель `Control UI` доступна только через loopback сервера. Для подключения с Mac откройте SSH-туннель `ssh -N -L 18789:127.0.0.1:18789 root@freedomvpn`, затем откройте `http://127.0.0.1:18789/`. Для входа выполните на сервере `docker exec openclaw-freedomvpn openclaw dashboard` и используйте выданную ссылку; не пересылайте её, так как она содержит токен шлюза.

Не добавляйте `.env`, `state/`, OAuth-креды и рабочие health-файлы в git. Не подключайте OpenClaw gateway напрямую к `vpn-backend`: к этой сети присоединяется только ограниченный MCP sidecar, который принимает соединения с отдельным MCP bearer-токеном.

## Telegram и права

Для группы оставьте `groupPolicy: allowlist`, единственный ID группы и `requireMention: false`. `configure-assistant.py` заново считывает Telegram-администраторов при запуске; повторно запустите его после смены состава администраторов. Тикеты, автоматически опубликованные отдельным ботом Freedom VPN, смогут запускать проверки данных, только если этот бот тоже является администратором группы. Любой ответ помощника виден участникам группы, поэтому не публикуйте чеки, provider IDs, секреты и необязательные персональные данные. Изменения выполняются только в личном чате владельца после точной строки подтверждения. Отключённый Privacy Mode нужен, чтобы Telegram присылал обычные сообщения группы; затем бота нужно удалить и добавить заново.

## Навыки OpenClaw

Навыки OpenClaw — это инструкции и рецепты, а не сами разрешения и API. Установленный набор можно посмотреть в панели `Control UI` или командой OpenClaw; готовность некоторых навыков зависит от приложений, секретов и настройки окружения. Инструменты Freedom VPN реализованы отдельно через MCP: `freedomvpn_health` выполняет текущие публичные DNS/HTTPS-проверки из сети Docker-сервера и показывает снимок состояния хоста с указанием его возраста. Он не подтверждает доступность из сети конкретного клиента. Другие инструменты поддерживают диагностику, ответы клиентам из группы и административные действия владельца в личном чате.
