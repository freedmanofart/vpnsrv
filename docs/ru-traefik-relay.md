# Ретранслятор Traefik на российской ноде

Состояние: приостановлен. Главный сервер и бот пока публикуют ссылки с IP-
адресом, поэтому ретранслятор сейчас не используется. Сервис Compose включён в
профиль `public-relay`; перед восстановлением его записей SNI в nginx профиль
нужно включить явно.

`traefik.me` — публичная служба DNS с маской, а не DNS-сервер, который нужно
устанавливать на российскую ноду. Имена вроде
`cabinet.176.108.250.142.traefik.me` разрешаются в `176.108.250.142`; контейнер
Traefik отвечает за маршрутизацию HTTP и TLS-сертификаты ACME.

Публичный TCP-порт 443 по-прежнему принадлежит nginx stream/KIT. После включения
nginx направляет три веб-имени на Traefik по адресу `127.0.0.1:8448`, используя
действующий путь с протоколом PROXY. Traefik слушает публичный TCP-порт 80 для
проверки HTTP ACME и перенаправлений, а его HTTPS-точка входа доступна только
локально. Не публикуйте Traefik напрямую на порту 443 и не меняйте существующие
SNI-маршруты VPN.

## Имена хостов

| Имя хоста | Назначение |
| --- | --- |
| `site.176.108.250.142.traefik.me` | Публичный сайт |
| `cabinet.176.108.250.142.traefik.me` | Веб-кабинет и ссылки для пользователей |
| `admin.176.108.250.142.traefik.me` | Панель администрирования сервиса |
Traefik передаёт запросы главному серверу через уже настроенное имя Tailscale
Funnel. При этом текущие API-порт главного сервера и порты VPN не меняются.

## Установка и обновление

Скопируйте `deploy/traefik` в `/opt/freedomvpn-traefik` на российской ноде,
создайте `data/acme.json` с правами `0600` и владельцем `root`, затем запустите
сервис командой
`docker compose --profile public-relay up -d`. Добавьте три записи из
`deploy/traefik/nginx-sni-map.conf` в активную карту
`/etc/nginx/kit-stream.conf`, выполните `nginx -t` и перезагрузите nginx только
если проверка прошла. Перед редактированием создайте датированную резервную
копию исходной карты.

На главном сервере задайте для `PUBLIC_BASE_URL` и `WEB_CABINET_URL` имя
кабинета, для `WEB_SITE_URL` — имя сайта, а `ADMIN_DASHBOARD_URL` направьте на
путь `/admin` административного хоста. Сначала сохраните резервную копию `.env`,
затем перезапустите только `api` и `bot`. Внутренний адрес
`API_URL=http://api:8000` не меняйте. Новые уведомления Telegram и ссылки на
подписки будут использовать новые имена; уже отправленные сообщения не
изменятся.

## Проверка и откат

Убедитесь, что DNS с маской возвращает адрес российской ноды, доступны TCP-порты
80 и 443, Traefik получает доверенный сертификат ACME, а каждый хост возвращает
ожидаемую страницу сайта, кабинета или админки. Проверьте, что прежние ссылки по
IP и Tailscale также работают, а существующие SNI-маршруты VPN Швеции и России
не изменились.

Для отката восстановите сохранённую карту nginx и перезагрузите его, остановите
проект Traefik Compose, затем верните прежний `.env` главного сервера и
перезапустите `api` и `bot`. Старые публичные ссылки по IP и Tailscale останутся
доступны как резервные.
