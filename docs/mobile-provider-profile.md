# Мобильный профиль Freedom VPN

Мобильный API выдаёт Android/iOS-клиенту только scoped device token и VPN URI
назначенных профилей. Сервисный токен и доступ к 3x-ui на телефон не попадают.

## Тестовый доступ

`POST /v1/client/trial` принимает UUID установки, имя устройства и платформу
`android` или `ios`. Новая установка получает непубличную подписку на
`CLIENT_TRIAL_DAYS` дней и все доступные конфигурации, опубликованные в
`vpn_node_configs`. Для VLESS сервер создаёт отдельного клиента в 3x-ui; для
другого протокола используется готовый `client_uri`, если он задан в конфигурации
ноды.

Один `install_id` может получить только одну пробную подписку. Повторный запрос
до окончания срока ротирует device token, но не создаёт второй доступ. После
окончания срока API отвечает `403`. Для защиты публичной выдачи включите rate
limit на reverse proxy; UUID установки не является аппаратной аттестацией.

Настройки:

- `CLIENT_TRIAL_ENABLED=true` — включить выдачу;
- `CLIENT_TRIAL_DAYS=30` — срок теста;
- `CLIENT_TRIAL_TRAFFIC_LIMIT_BYTES=0` — без отдельной квоты, положительное
  значение задаёт общий лимит upload+download;
- `CLIENT_PROVIDER_NAME`, `CLIENT_ANNOUNCEMENT` и `CLIENT_ANNOUNCEMENT_URL` —
  данные карточки провайдера;
- `CLIENT_CHANNEL_URL`, `CLIENT_SUPPORT_URL`, `CLIENT_WEBSITE_URL`,
  `CLIENT_ACCOUNT_URL`, `CLIENT_RENEWAL_URL` — кнопки карточки.

## Профиль и синхронизация

`GET /v1/client/profile` с Bearer device token возвращает все активные профили
подписки. У каждого профиля есть стабильный `profile_id` формата `node_id:protocol`,
страна, протокол, доступность, задержка ноды, конфигурация и текущие счётчики.
Кнопка синхронизации в приложении повторяет этот запрос и обновляет управляемые
профили.

Профиль также содержит название плана, объявление, разрешённые ссылки провайдера,
время обновления и объект `usage` с upload/download, общей квотой и остатком.
Ping до конкретной ноды измеряется приложением с телефона; `latency_ms` из API
остаётся диагностикой backend.

## Трафик

При чтении мобильного профиля API запрашивает актуальные `clientStats` у 3x-ui
для каждого VLESS-клиента и сохраняет последнее значение в `vpn_clients`.
Если панель временно недоступна, возвращаются последние сохранённые счётчики.
Суммарная квота считается как upload+download по профилям подписки; текущую
скорость приложение показывает локально по туннелю.

## Код провайдера и диплинк

После тестового периода используется существующий одноразовый код:

```text
freedomvpn://activate?code=12345678&name=My%20phone
```

Оператор выпускает его через `POST /v1/client/activation-codes`, а приложение
обменивает через `POST /v1/client/activate`. Сервисные секреты и готовые VPN URI
в диплинк не помещаются. Полный контракт выпуска и активации описан в
[`provider-code-mobile.md`](provider-code-mobile.md).

## Миграция и проверка

Перед обновлением сделайте резервную копию PostgreSQL и выполните:

```bash
docker compose run --rm api alembic upgrade head
python3 scripts/configctl.py validate
```

Новая миграция добавляет хеш установки, кеш счётчиков, квоту подписки и меняет
ограничение активных клиентов с «один на подписку» на «один на ноду и протокол».
Проверьте `/health`, выдачу trial на тестовой установке, синхронизацию списка,
подключение каждой страны и рост счётчиков в карточке.
