## Как поддерживать документацию

- Изменили топологию или набор профилей — обновите `architecture.md`.
- Изменили API, приложение или порядок эксплуатации — обновите профильную
  инструкцию и ссылки здесь.
- Новую страницу добавьте в этот каталог и в список документов админки
  (`ADMIN_DOCS` в `api/app/api/routes/admin.py`).
- Не копируйте секреты, полные VPN URI, приватные ключи и временные коды в docs.
