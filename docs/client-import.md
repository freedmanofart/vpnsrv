# Импорт клиентских конфигураций

Актуально на 31 октября 2026 года. Общая ссылка из уведомления ведёт на
`GET /v1/client/import-apps/{token}`. Ссылка содержит подписанный токен и
является секретом: не передавайте её третьим лицам и не записывайте полный URL
в логи. Сервер отвечает с `Cache-Control: no-store` и
`Referrer-Policy: no-referrer`. Журнал API маскирует токен в путях подписки,
импорта, QR и загрузки `.conf`.

## Путь пользователя

1. После оплаты клиент открывает одну ссылку из Telegram или email.
2. INCY, Freedom VPN и V2rayTUN запускаются с этой страницы непосредственно
   через схему приложения; на Android для INCY и Freedom VPN используется
   `intent://`. Дополнительная страница подтверждения не нужна.
3. Для Amnezia VPN на той же странице доступен выбор отдельного профиля.
   Ключ копируется в буфер обмена для вставки в Amnezia VPN. Прямое открытие
   `vpn://` не предлагается: приложение не регистрирует эту схему на всех
   платформах. Для AmneziaWG и обычного WireGuard доступны и текстовый ключ,
   и `.conf` для импорта файла. Профили загружаются из актуальной выдачи KIT
   и дополнительных нод, поэтому изменения списка видны при повторном
   открытии страницы.

Старые URL `/v1/client/import/{token}`,
`/v1/client/freevpn-import/{token}` и
`/v1/client/v2raytun-import/{token}` остаются рабочими для уже отправленных
сообщений. Старый `/v1/client/amnezia-import/{token}` перенаправляет на
раздел Amnezia общей страницы. Ссылка остаётся привязана к текущей активной
подписке пользователя, даже если её клиент был перевыпущен при продлении.

## Совместимость Amnezia VPN

Импортёр AmneziaVPN принимает отдельные `vpn://`, VLESS, VMess, Trojan и
Shadowsocks-ключи. Из VLESS в списке остаются проверяемые импортёром
TCP/REALITY, WebSocket и gRPC. VLESS xHTTP не предлагается: текущий импортёр
не переносит параметры этого транспорта. Hysteria2 и TUIC в Amnezia VPN
не выдаются. Обычный `wireguard://` преобразуется в `.conf` и в текстовый
`vpn://` ключ с содержимым конфигурации; AmneziaWG берётся из KIT и доступен
тем же способом. Пользователь добавляет каждый профиль отдельно.

Ошибка `103 Background service is not running` возникает на стороне
установленного приложения до попытки VPN-подключения. На macOS проверьте
`Системные настройки → Основные → Объекты входа и расширения →
Privacy Technologies OU`: фоновая активность должна быть разрешена. Затем
перезапустите AmneziaVPN. Официальная инструкция:
[коды ошибок AmneziaVPN](https://docs.amnezia.org/troubleshooting/error-codes/).

Amnezia VPN пока не поддерживает автоматическое обновление произвольной
подписки с несколькими протоколами. Пользователь импортирует выбранные
профили по одному; при изменении ключа их нужно импортировать повторно.
Не обещайте автоматическую синхронизацию Amnezia в уведомлениях.

Основание для ограничений: [инструкция по вставке текстового ключа](https://docs.amnezia.org/documentation/instructions/connect-via-text-key/),
[FAQ о `vpn://`](https://docs.amnezia.org/faq/) и
[исходный код импортёра](https://github.com/amnezia-vpn/amnezia-client/blob/dev/client/core/controllers/selfhosted/importController.cpp).

## Проверка после выкладки

- Для активной подписки откройте общую ссылку на Android и настольном браузере:
  кнопки INCY/Freedom VPN/V2rayTUN должны запускать приложение сразу.
- Проверьте, что Amnezia показывает VLESS, VMess, Trojan, Shadowsocks,
  AmneziaWG и WireGuard, если такие профили есть у клиента, но не показывает
  Hysteria2, TUIC и xHTTP.
- Скачайте по одному `.conf` для AmneziaWG и WireGuard, затем проверьте импорт
  на устройстве. Доступность файла не доказывает успешное VPN-подключение.
- Для неверного токена страница должна отвечать `404`, для неактивной
  подписки `410`; старые URL не должны обходить эти проверки.
